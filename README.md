# The-Puthing-Around-cache-editing-script
This is the official repository for the script used to automate Puthing Around.

This script is AutoKnight's version of the script as it is the only known documented script to exist, and the script showcased in a 10 seconds clip by IBANT has similar fuctionality to AutoKnight's script.

The files, including the dictionary used is available in Downloads. There are some required photos to use the script, which is in the zip file "puths.zip" along with everything else. The source code is also available in Downloads.
